# Claude Code Desktop Redesign

Anthropic 于 2026年4月发布的 Claude Code 桌面应用全新设计，专为并行 agent 工作构建。

## 主要更新

### 并行会话管理
- 全新侧边栏管理多个会话
- 支持并行运行多个会话
- 拖放式布局排列工作区

### 集成环境
- 集成终端和文件编辑器
- 更快的 diff viewer
- 支持 HTML/PDF 内嵌预览

### 性能提升
- 重建可靠性和速度
- 流式响应

### 平台支持
- SSH 支持扩展到 Mac 和 Linux
- 支持本地或云端运行

## 定价

适用于 Pro、Max、Team 和 Enterprise 计划，以及 Claude API。
