# SAP

全球最大的企业应用软件供应商，服务 40 万家企业客户。

## 关键人物

**Philipp Herzig** — SAP CTO，在 No Priors 播客中深度阐述 SAP 的 AI 战略。

## AI 战略要点（2026-04-26）

### 三层变革框架
1. **UI 层 → Generative UI**：动态生成界面，多模态主动化
2. **业务流程层 → Agent 驱动**：融合结构化/非结构化数据
3. **数据层 → 统一语义模型**

### 核心产品/技术
| 名称 | 说明 |
|------|------|
| **Joule for Consulting** | 咨询顾问 AI 助手，减少 30% 工作量 |
| **SAP Knowledge Graph** | 自然语言与结构化数据的桥梁 |
| **RPT-1** | 关系预训练 Transformer，用于表格数据预测 |

### 商业模式转变
Seat-based → Hybrid Consumptive → Outcome-based（与客户共同演进）

### 观点
- "规模是最大挑战"——20,000 API、40 万客户
- "LLM 不够做预测分析"→ RPT-1
- "Eval 是最重要的开发实践"
- "我们的工作是让技术隐形"
