## 公司定位

自称为 foundational AI company，同时在 EBM 和 LLM 两个方向工作。初始原型在 LLM 上构建，长期目标是将 EBM 插入替代。产品聚焦于 **AI 正确性** —— 验证 AI 在关键任务系统中的输出是否正确、合理。

## 核心技术：EBM with Latent Variables

正式名称：**Energy Based Reasoning Model with Latent Variables**
内部代号：**Kona**（源自咖啡文化，Kona 是喜爱的咖啡种类）

### 技术差异化

1. Token-free 架构（无猜谜游戏）
2. 训练过程中可实时检查内部状态
3. 双重验证（内部自对齐 + 外部形式化证明）
4. 擅长稀疏数据处理
5. 可被形式化强制遵循约束规则

## 商业策略

### 兼容而非替代

明确表示不希望被定位为 LLM 替代品，而是作为 LLM 的**兼容增强层**：
- LLM 处理语言相关任务
- EBM 处理空间推理、数据分析、形式化验证
- 降低 LLM 产品组合公司的成本

### 目标市场

- 数字资产公司（银行、交易公司）
- 生物制药（基因分析、血液标记）
- 关键基础设施（电网、能源分配）
- 应用工程（芯片设计、代码生成）
- B2B 隐私敏感场景（企业自有定制 AI）

## 行业观点

Eve 对 LLM 投资生态的分析：
- **沉没成本锁定**: 数十亿美元投入无法放弃
- **循环交易生态**: LLM 公司 ↔ 数据中心 ↔ 硬件 ↔ 云
- **大科技有内部 EBM 研究**: 视为对 EBM 方向的积极信号
- **激进创新资金占比小**: 大部分资金流向增量式 LLM 改进
