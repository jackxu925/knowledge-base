# OpenAI Codex

OpenAI 推出的 AI 编程工具，2026 年 4 月 17 日发布重大升级，从编码助手升级为自主性 AI 开发工具。

## 核心能力（2026-04 升级后）

| 功能 | 详情 |
|---|---|
| 多智能体工作流 | 并行部署专门化 Agent 处理编码/调试/测试 |
| 桌面应用控制 | 后台控制 macOS 应用运行测试（限 macOS） |
| 持久化记忆 | 跨会话保留上下文和用户偏好 |
| 多模态 | 结合 GPT-image-1.5，支持 UI/图像/代码一体化 |
| 插件生态 | 90+ 新插件（Atlassian、CircleCI、GitLab 等） |

## 竞争定位

- **传统优势**：速度快，侧重执行
- **本次升级目的**：弥补长复杂工作流短板，增加自主性
- **主要竞争对手**：[[Cursor]]、Claude Code（Anthropic）
