# James Cadwallader

## Overview

Co-founder and CEO of **[[ProFound]]**, an AI-era marketing platform. Key thinker in the **[[Agent-Led-Growth]]** (ALG) paradigm.

## Known For

- Coining/popularizing **Agent-Led Growth (ALG)** as the successor to SEO
- **Dead Internet Theory timeline prediction**: 3 years until agent-only web browsing
- **Vertical integration thesis**: AI labs will acquire social networks for fresh human data
- **System prompt advertising model**: Future ads = targeted system prompts, not banners
- **"Fleshy API" metaphor**: Humans as the interface between reality and the internet in an age of pre-trained models

## Key Arguments

| Thesis | Summary |
|---|---|
| **ALG replaces SEO** | Content built for agents (100x surface area) vs. humans (top 5 links) |
| **Platform divergence** | Gemini→YouTube, ChatGPT→Reddit/LinkedIn, Claude→real-time web |
| **Dead Internet ~3yr** | Human web browsing → 0, ad revenue → 0, publishing incentive → 0 |
| **Ad evolution** | From banners to system prompts with hyper-personalization |
| **Social media as human zone** | Ideas exchanged for status/money; AI labs integrate vertically |
