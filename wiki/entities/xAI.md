# xAI

埃隆·马斯克（Elon Musk）旗下人工智能公司，以 Grok 系列大模型闻名。2026 年 4 月宣布进军 AI 编程领域。

## 核心产品

### Grok 大模型系列
- 面向 X（原 Twitter）平台的对话式 AI
- 以「幽默、反叛」人格著称，区别于主流模型的保守风格
- 拥有 X/Twitter 平台的海量实时数据优势

### Grok Build & Grok CLI（即将发布，2026-04）

据多家科技媒体 4 月中旬披露：

| 产品 | 形态 | 定位 |
|------|------|------|
| **Grok Build** | IDE 集成式编程助手 | 类似 Cursor / GitHub Copilot |
| **Grok CLI** | 命令行编程工具 | 类似 Claude Code / Codex CLI |

**竞争定位**：
- 正面竞争对象：[[Claude Code]]（Anthropic）、OpenAI Codex、Google Jules
- xAI 优势：自有大模型 + X/Twitter 海量代码数据
- 标志着 AI Coding 赛道从「三足鼎立」进入 **四大赛场时代**

## 战略意义

- 马斯克入局将使本已白热化的 AI Coding 竞争进一步升级
- 与 SpaceX 拟收购 Cursor 的动向形成呼应——马斯克生态正在系统性布局 AI 编程能力
- 若 Grok Build/CLI 表现出色，可能重塑当前 OpenAI/Anthropic/Cursor 的竞争格局

## 注意事项

截至 2026-04-28，Grok Build / Grok CLI 尚未见官方正式发布声明，具体功能和发布时间仍需关注 xAI 官方消息。
