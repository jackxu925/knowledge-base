## 核心主张

**AI 正在重塑初创公司的构建方式**：创始人角色从个人贡献者转变为「协调者（orchestrator）」，未写过一行代码的创始人可以交付生产级应用、在扩大规模前就实现营收。

## 手册框架：四阶段生命周期

| 阶段 | 核心任务 |
|------|---------|
| **Idea（构想）** | 用 AI 验证问题假设、绘制竞争格局、开展客户发现 |
| **MVP** | 架构、范围、安全实践，防止技术债务积累 |
| **Launch（发布）** | 用 agentic workflows 替代创始人注意力的发布操作系统 |
| **Scale（规模化）** | 产品矩阵 + PMF 衡量框架 |

## 六大主题

1. **问题验证与市场调研** — AI 驱动的客户发现与竞争格局分析
2. **MVP 架构与安全实践** — 防止 AI 生成代码积累技术债务
3. **PMF 衡量框架** — 区分真正的产品市场契合度与早期炒作
4. **发布阶段 OS** — agentic workflows 替代创始人注意力
5. **产品矩阵** — Chat / Claude Cowork / Claude Code 在各阶段的使用场景
6. **创始人故事** — Ambral、Anything、Carta Healthcare、HumanLayer、Vulcan Technologies

## 产品矩阵（重点）

| 工具 | 适用场景 |
|------|---------|
| **Claude Chat** | 策略思考、写作、分析，无需编码 |
| **Claude Cowork** | 多人协作、异步工作流 |
| **Claude Code** | 生产级代码生成、agentic 编程任务 |
