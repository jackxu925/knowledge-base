# Codex-Native

由 Every CEO Dan Shipper 提出的一种软件设计范式：应用设计为在 AI agent 的应用内浏览器中使用，agent 和人类可以共享完整上下文并同时操作。

## 核心概念

> "Apps designed to be used inside the in-app browser of your agent of choice. The agent can use it and you can use it too, full context is shared, and you can both see what the other is doing."

## 衍生概念

- **Codex-native**: 在 Claude Code 内置浏览器中使用
- **Cowork-native**: 在 Cowork 内置浏览器中使用  
- **Cursor-native**: 在 Cursor 内置浏览器中使用

## 商业机会

- 为 AI agent 内置浏览器专门设计的应用
- 深度集成 agent 上下文的应用
- 实时协作式工作流

## 相关工具

- Claude Code 内置浏览器
- Cursor 内置浏览器
- Codex 上下文共享
