# Generative UI（生成式界面）

SAP CTO Philipp Herzig 提出的企业软件 UI 范式转变：从**预设的固定界面**转向 **AI 动态生成界面**。

## 核心变化

| 旧范式 | 新范式 |
|--------|--------|
| 设计师精心设计 UI | AI 根据任务动态生成界面 |
| 用户学习如何操作 | 系统理解用户意图并呈现所需信息 |
| 被动响应 | 主动推送（"早上好 Sarah，销售订单在下降..."） |
| 单一模态 | 多模态（文本 + 图表 + 数据 + 操作建议） |

## 关键能力

1. **分析性问答**：自然语言 → SQL → 数据展示
2. **深度研究**：结合企业数据回答复杂业务问题（如关税变化对供应链的影响）
3. **主动通知**：系统夜间运行，早上汇报异常和建议

## 设计哲学

> "The time is clearly over where you design software that requires the intelligence to sit in front of the computer." — Philipp Herzig

## 与相关概念的关系

- [[Post-Prompting World]]：Generative UI 是后提示词世界的前端体现——不再需要用户学习 UI，AI 理解意图即可
- [[Managed Agents]]：Generative UI 是 Agent 的输出层
