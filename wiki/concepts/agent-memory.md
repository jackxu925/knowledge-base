# Agent Memory

**标签：** #Agent #Memory #Knowledge-System #Persistent-State #GBrain

---

## 定义

Agent Memory 是 AI Agent 的持久记忆系统，使 Agent 能够跨会话累积知识、沉淀经验、持续进化。与无状态 Agent（每次对话从零开始）相对，持久记忆是 Agent 从"工具"进化为"伙伴"的关键基础设施。

## 核心问题

> "我 Agent 经常忘记半小时前说了什么。"

当前大多数 AI 助手的问题：
- 每次对话都是全新的开始
- 没有记忆累积
- 没有知识沉淀
- 更谈不上智能进化

## 三层记忆架构

| 层 | 存储内容 | 生命周期 | 查询方式 |
|----|----------|----------|----------|
| **世界知识（gbrain）** | 人物、公司、会议、想法、媒体 | 长期持久 | `gbrain search`、`gbrain query` |
| **Agent 内存** | 偏好、决策、操作配置 | 中长期 | `memory_search` |
| **会话上下文** | 当前对话 | 短期 | 自动管理 |

## 知识模型：编译真理 + 时间线

```markdown
---
type: concept
title: [概念名称]
tags: [标签]
---

[编译真理：当前最佳理解，随证据更新而重写]

----
- [日期]: [事件/证据]
- [日期]: [事件/证据]
```

- **编译真理**（`---` 上方）：当前最佳理解，新证据出现时被重写
- **时间线**（`---` 下方）：只追加的证据轨迹，永不编辑

**哲学：** 编译真理是答案，时间线是证明。

## 复合增长循环

```
信号到达（会议、邮件、推文、链接）
 → Agent 检测实体（人物、公司、想法）
 → 读取：先检查大脑
 → 带着完整上下文回应
 → 写入：用新信息更新大脑页面
 → 同步：为下次查询索引更改
```

**关键洞察：** 每次通过这个循环都会增加知识。差异每天都在复合增长。

## 两种 Agent 对比

| 维度 | 无状态 Agent | 有记忆 Agent |
|------|-------------|-------------|
| 上下文 | 仅当前会话 | 完整历史 + 世界知识 |
| 学习 | 不学习 | 每次对话都变聪明 |
| 一致性 | 每次回答可能矛盾 | 基于累积知识保持一致 |
| 个性化 | 无 | 基于历史交互个性化 |
| 实用性 | 工具 | 伙伴 |

## 技术实现要点

### 搜索机制
- **关键词搜索**：精确短语匹配
- **向量搜索**：语义概念匹配
- **RRF 融合**：结合两者优势
- **多查询扩展**：捕捉未想到的表述

### 基础设施
- **Postgres + pgvector**：支持大规模混合搜索
- **嵌入模型**：text-embedding-3-large
- **LLM 分块**：Haiku 用于多查询扩展

### 关键特性
- **梦境循环**：Agent 在后台持续整理记忆
- **实体检测**：自动识别人物、公司、想法
- **来源归属**：所有信息可追溯
- **反向链接**：自动维护页面间引用关系
