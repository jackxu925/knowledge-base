# Hybrid Search

**标签：** #Search #Vector-Search #Keyword-Search #RRF #Agent

---

## 定义

Hybrid Search（混合搜索）是结合多种搜索机制（关键词搜索、向量搜索、融合算法）的检索策略，旨在同时满足精确匹配和语义理解的需求。在 Agent 记忆系统中，它是实现高效知识检索的核心技术。

## 三种搜索机制

### 1. 关键词搜索（Keyword Search）

- **原理**：基于倒排索引的精确/模糊文本匹配
- **优点**：精确短语匹配、速度快、可解释
- **缺点**：无法理解同义词、概念关联
- **示例**：搜索 "Pedro" 精确找到人名

### 2. 向量搜索（Vector Search）

- **原理**：将文本转换为高维向量，基于语义相似度匹配
- **优点**：理解概念关联、同义词、语义相近表达
- **缺点**：可能错过精确短语、嵌入可能被周围文本稀释
- **示例**：搜索 "忽略传统智慧" 找到 "天才巴士票理论"

### 3. RRF 融合（Reciprocal Rank Fusion）

- **原理**：结合关键词和向量搜索的结果排名
- **公式**：`score = Σ(1 / (k + rank))`
- **优点**：兼顾精确性和语义理解
- **效果**：两者都对，多查询扩展捕捉未想到的表述

## 为什么需要混合搜索

| 场景 | 仅关键词 | 仅向量 | 混合搜索 |
|------|----------|--------|----------|
| 精确人名 | ✅ | ❌ | ✅ |
| 概念关联 | ❌ | ✅ | ✅ |
| 同义词 | ❌ | ✅ | ✅ |
| 精确短语 | ✅ | ⚠️ | ✅ |
| 语义相似 | ❌ | ✅ | ✅ |

## 在 GBrain 中的应用

```
查询 → 多查询扩展（LLM 生成变体）
     → 关键词搜索 → 排名列表 A
     → 向量搜索 → 排名列表 B
     → RRF 融合 → 最终排名
     → 返回结果
```

### 多查询扩展

- **作用**：捕捉用户未想到的表述方式
- **实现**：LLM（如 Haiku）生成查询变体
- **示例**：
  - 原始查询："竞争动态"
  - 扩展："竞争对手"、"市场竞争"、"行业格局"
