# Token Maxing

## 定义

在 AI Native 公司中，**最大化 AI Token / API 的使用量**，用算力成本替代人力成本，作为新的资源优化逻辑。关键转变是最大化 Token 使用量，而不是员工数量。

## 核心理念

- 一个拥有 AI 工具的人可以完成前 AI 时代需要一个大型工程团队才能完成的工作
- 工程、设计、人力资源和行政团队都会大幅精简
- 扩大规模意味着增加 API 使用量，而非线性增加员工数量

## 成本视角

| 传统公司 | AI Native 公司 |
|---------|--------------|
| 主要成本：员工薪资 | 主要成本：API 账单 + 少量精英员工 |
| 扩大规模 = 招人 | 扩大规模 = 增加 Token 使用量 |
| 人力成本随人数线性增长 | API 成本随使用量亚线性增长 |

## 投资者新指标

未来投资者可能关注：
- **每员工收入**（Revenue Per Employee）
- **API 成本占收入比例**
- **Token 使用效率**

## 心态转变

> 创业公司应愿意承担**令人不舒服的高 API 账单**（如 OpenAI、Anthropic 账单每月几万甚至几十万美元），因为它正在取代本来昂贵得多、臃肿得多的员工数量。

## 风险

- 对单一 API Provider 的依赖
- API 价格变动风险
- 需要精细化的成本监控
