# Software Factory（软件工厂）

## 定义

一种新兴软件开发范式：人类编写**规格（Specification）**和定义成功的**测试**；[[AI Agent]] 生成实现和代码，并迭代直到测试通过。它是[[测试驱动开发]]（TDD）的下一个演进。

## 运作方式

```
人类：定义问题 + 编写规格 + 设计测试
          ↓
AI Agent：生成代码实现
          ↓
测试框架：自动验证
          ↓
[通过] → 合并代码
[失败] → AI Agent 迭代修复 → 再次测试
```

## 关键转变

| 传统开发 | Software Factory |
|---------|-----------------|
| 人类写代码 | 人类写规格和测试 |
| 代码审查 | 测试验证 |
| 代码是核心资产 | 规格和测试是核心资产 |
| 瓶颈：写代码速度 | 瓶颈：明确需求和验证正确性 |

## 真实案例

**strongDM**：AI 团队已将代码仓库推进到**不包含任何手写代码**，只有规格和测试工具。目标是建立基本消除人类编写或审查代码需要的系统。

## 角色转变

工程师的工作从"写代码"转变为：
1. **定义问题** — 清晰描述要解决的问题
2. **设计架构** — 规划系统结构和接口
3. **编写测试** — 定义成功的标准

代码本身成为可由 AI 大量生成的商品。
