# Knowledge Model

**标签：** #Knowledge-Management #Agent-Memory #Information-Architecture #GBrain

---

## 定义

Knowledge Model（知识模型）是组织和管理知识的结构化方法。在 Agent 记忆系统中，它定义了信息如何被存储、更新、检索和关联。GBrain 采用的"编译真理 + 时间线"模型是一种经过验证的知识管理范式。

## GBrain 知识模型：编译真理 + 时间线

### 结构

```markdown
---
type: [concept|person|company|meeting|media]
title: [名称]
tags: [标签列表]
---

[编译真理：当前最佳理解，随证据更新而重写]

----
- [日期]: [事件/证据/来源]
- [日期]: [事件/证据/来源]
```

### 编译真理（Compiled Truth）

- **位置**：`---` 分隔符上方
- **性质**：当前最佳理解，可被重写
- **更新机制**：当新证据改变图景时重写
- **作用**：提供快速、准确的答案

### 时间线（Timeline）

- **位置**：`---` 分隔符下方
- **性质**：只追加的证据轨迹
- **规则**：永不编辑，只追加
- **作用**：提供可追溯的证据链

### 哲学

> 编译真理是答案，时间线是证明。

## 设计原则

### 1. 分离可变与不可变
- **编译真理**：可变，代表当前最佳理解
- **时间线**：不可变，代表历史证据

### 2. 来源归属
- 每个时间线条目都有日期和来源
- 所有信息可追溯

### 3. 实体类型化
- `concept`：概念、想法、理论
- `person`：人物档案
- `company`：公司信息
- `meeting`：会议记录
- `media`：书籍、文章、视频

### 4. 标签系统
- 便于分类和检索
- 支持多维度关联

## 对比其他知识管理方法

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **编译真理 + 时间线** | 答案快速，证据完整 | 需要维护编译真理 | Agent 记忆、个人知识库 |
| **纯时间线** | 简单，无信息丢失 | 查找答案慢 | 日志、审计 |
| **纯编译** | 查询快 | 可能丢失历史 | 百科、FAQ |
| **双向链接** | 关系清晰 | 维护成本高 | 思维导图、笔记 |

## 在 Agent 系统中的应用

### 读取流程
1. Agent 接收查询
2. 搜索相关页面
3. 读取编译真理获取当前理解
4. 如需验证，查看时间线证据

### 写入流程
1. Agent 获取新信息
2. 检测相关实体
3. 更新编译真理（如需要）
4. 追加到时间线
5. 同步索引
