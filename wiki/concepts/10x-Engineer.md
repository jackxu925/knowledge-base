# 千倍工程师 / 万倍工程师

## 定义

借助 [[AI Agent]] 系统，单个工程师可以完成过去需要整个团队才能完成的工作。这是传统"10x 工程师"概念在 AI 时代的指数级放大。

## 层级

| 级别 | 含义 | 实现方式 |
|------|------|---------|
| 10x | 效率是常人的 10 倍 | 技能、经验、工具熟练度 |
| 100x | 效率是常人的 100 倍 | AI 辅助编程（Copilot 等） |
| **1000x** | 效率是常人的 1000 倍 | [[Software Factory]] + AI Agent 系统 |
| **10000x** | 效率是常人的 10000 倍 | 完全自主的 AI 编码系统 |

## 实现条件

1. **被 AI Agent 系统包围** — 不是用一个工具，而是构建完整的 AI 工作流
2. **专注于规格和架构** — 不写实现代码，只定义问题和成功标准
3. **闭环反馈** — 系统能自动测试、迭代、改进

## 案例

**strongDM**：代码仓库已不包含任何手写代码，一个工程师 + AI Agent 系统管理整个代码库。

## 与 Token Maxing 的关系

千倍工程师的实现依赖 [[Token Maxing]] — 愿意支付高 API 账单来换取人力成本的指数级降低。
