# Software as New Media

## Definition

The thesis that **when code production cost approaches zero marginal cost, the software industry restructures to resemble the media industry**, where competitive advantage shifts from engineering capability to distribution, audience reach, and content-like qualities of software products.

## Core Argument

### The Cost Collapse

- AI coding agents (Codex, Claude Code, etc.) dramatically reduce the cost of writing software
- When code generation is nearly free, **engineering is no longer a moat**
- What was previously a supply-constrained market (not enough engineers) becomes demand-constrained (too much software)

### Structural Shifts

| Old Paradigm (Engineering Era) | New Paradigm (Media Era) |
|---|---|
| Engineering talent is scarce | Code is commodity |
| Distribution is solvable problem | Distribution IS the moat |
| Build great product, they will come | Audience/attention is everything |
| Features differentiate | Brand/narrative/community differentiate |
| High switching costs | Low switching costs, loyalty through habit |

## Implications

### For Startups

- Speed-to-market becomes less important than speed-to-audience
- Developer experience (DX) matters less than user network effects
- Open source becomes default expectation; value moves up the stack
- "Build in public" and creator-style marketing becomes essential competitive strategy

### For Enterprise

- Custom software development cost collapses
- CIO role shifts from technology buyer to platform/orchestrator
- Vendor lock-in through ecosystem, not codebase
- Internal tools can be generated on-demand

### For Individual Builders

- **Solo founders gain leverage**: Can ship products previously requiring teams
- But face new challenge: discoverability in a flood of AI-generated software
- Peter Yang's playbook ($50-100/month pricing, day-one revenue, <20% churn) becomes template

## Counterarguments & Risks

- **Quality floor**: AI-generated software may have hidden defects
- **Maintenance burden**: Generated code still requires maintenance at same rate
- **Differentiation crisis**: If everyone can build anything, what makes your thing special?
- **Security surface**: More software = larger attack surface

## Relationship to Other Concepts

- **[[AI-Coding]]**: The enabling technology driving this shift
- **[[Agent-Led-Growth]]**: In ALG world, software products also compete for agent recommendations, adding another distribution channel
- **[[Jevons-Paradox]]**: Cheaper code may increase total software demand rather than reducing it (similar to cheaper energy increasing energy consumption)
