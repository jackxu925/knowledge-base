# Compound Growth

**标签：** #Knowledge #Growth #Agent #Learning #Long-term

---

## 定义

Compound Growth（复合增长）在 Agent 记忆系统中指知识通过持续累积产生的指数级增长效应。每次交互、每次学习、每次更新都在增加 Agent 的知识基础，使得 Agent 随着时间的推移变得越来越聪明。

## 核心循环

```
信号到达（会议、邮件、推文、链接）
    ↓
Agent 检测实体（人物、公司、想法）
    ↓
读取：先检查大脑（带着完整上下文）
    ↓
回应（基于累积知识）
    ↓
写入：用新信息更新大脑页面
    ↓
同步：为下次查询索引更改
    ↓
[循环重复，知识累积]
```

## 两种 Agent 的对比

| 维度 | 无状态 Agent | 有复合增长的 Agent |
|------|-------------|-------------------|
| 第 1 天 | 有一定能力 | 有一定能力 |
| 第 7 天 | 能力不变 | 知识库扩大，更了解用户 |
| 第 30 天 | 能力不变 | 掌握完整上下文，能预测需求 |
| 第 1 年 | 能力不变 | 拥有丰富的关系网络和历史洞察 |

## 复合增长的来源

### 1. 信号累积
- 会议记录
- 邮件往来
- 社交媒体
- 阅读材料
- 日历事件

### 2. 关系网络
- 人物之间的联系
- 公司与人物的关系
- 概念之间的关联
- 历史交互记录

### 3. 模式识别
- 用户偏好
- 常见需求
- 决策模式
- 时间规律

## Garry Tan 的实例

**一周内的增长：**
- 10,000+ markdown 文件
- 3,000+ 人物档案
- 13 年日历数据
- 5,800+ Apple Notes

**效果：**
- "谁认识 Pedro 和 Diana？" → 跨 3,000+ 人物页面引用社交图谱
- "30分钟后跟 Jordan 的会议准备" → 拉取档案、共同历史、近期活动

## 关键洞察

> 没有这个循环的 Agent 从过时的上下文中回答。拥有这个循环的 Agent 每次对话都会变得更聪明。差异每天都在复合增长。

## 实现要点

1. **持久存储**：知识必须长期保存（Postgres + pgvector）
2. **自动索引**：新信息自动进入搜索索引
3. **实体检测**：自动识别和关联新实体
4. **来源归属**：所有信息可追溯，确保可信度
5. **梦境循环**：后台持续整理和丰富知识

## 与简单累积的区别

| 简单累积 | 复合增长 |
|----------|----------|
| 线性增长 | 指数增长 |
| 信息堆砌 | 知识关联 |
| 被动存储 | 主动整理 |
| 独立条目 | 关系网络 |
