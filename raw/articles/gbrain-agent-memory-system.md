## 摘要

GBrain 是 Y Combinator 总裁 Garry Tan 开源的"数字大脑"系统，为 AI Agent 提供持久记忆能力。它采用"编译真理 + 时间线"的知识模型，结合 Postgres + pgvector 实现混合搜索，让 Agent 每次对话都变得更聪明。

**GitHub：** https://github.com/garrytan/gbrain

---

## 缘起：一个困扰AI的古老问题

"我Agent经常忘记半小时前说了什么。"

这个看似简单的问题，却是当前AI助手发展最大的瓶颈之一。每次对话都是全新的开始——没有记忆累积，没有知识沉淀，更谈不上智能的进化。

Garry Tan 在 Twitter 上宣布：

> "如果你想让你的OpenClaw或HermesAgent能够完美记忆所有10,000+个markdown文件，GBrain来帮忙了。这正是我的OpenClaw/HermesAgent设置。MIT开源许可。"

这条推文在短短24小时内获得了 **3603个赞** 和 **381次转发**。

## GBrain 是什么

GBrain 是 Vannevar Bush 在1945年构想的 "Memex" 的现代实现——一个为思考者而生的数字大脑。

### Garry Tan 的数字大脑实验

**核心原则：**
- 每人一页文档
- 每家公司一页文档
- 顶部是与时俱进的编译真理
- 底部是只追加的时间线

**数据规模（一周时间）：**
- **10,000+** markdown 文件被索引和搜索
- **3,000+** 人物档案和关系历史
- **13年** 的日历数据（21,000+ 事件）
- **5,800+** Apple Notes（追溯到2009年）
- **280+** 会议记录和AI分析
- **300+** 组织化的原创想法
- **500+** 媒体页面（视频转录、书籍、文章）

**梦境循环：** Agent 在睡觉时持续运行，扫描当天对话，丰富缺失实体，修复损坏引用，整理记忆。

## 为什么需要 Postgres

| 文件数量 | 方案 |
|----------|------|
| 500 个 | `grep` 足够 |
| 10,000+ 个 | 需要混合搜索 |

**混合搜索能力：**
- **关键词搜索** — 精确查找人名
- **向量搜索** — 语义匹配
- **融合算法** — RRF 结合两者

毫秒级找到"三月份参加董事晚宴的所有人"，而非 30 秒的 grep 等待。

## 知识模型：编译真理 + 时间线

每个大脑页面遵循统一模式：

```markdown
---
type: concept
title: Do Things That Don't Scale
tags: [startups, growth, pg-essay]
---

[编译真理：当前最佳理解，随证据更新而重写]

----
- 2013-07-01: 发布于paulgraham.com
- 2024-11-15: 在W25启动会议中被引用
- 2025-02-20: 在关于AI Agent入职策略的讨论中被引用
```

- `---` 上方：**编译真理** — 当前最佳理解，新证据出现时被重写
- `---` 下方：**时间线** — 只追加的证据轨迹，永不编辑

编译真理是答案，时间线是证明。

## 复合增长的核心循环

```
信号到达（会议、邮件、推文、链接）
 → Agent 检测实体（人物、公司、想法）
 → 读取：先检查大脑（gbrain search、gbrain get）
 → 带着完整上下文回应
 → 写入：用新信息更新大脑页面
 → 同步：gbrain 为下次查询索引更改
```

每次通过这个循环都会增加知识。Agent 在会议后丰富人物页面，下次这个人出现时已有完整上下文。

## 技术架构

### 三层记忆系统

| 层 | 存储什么 | 如何查询 |
|---|---|---|
| **gbrain** | 人物、公司、会议、想法、媒体 | `gbrain search`、`gbrain query`、`gbrain get` |
| **Agent 内存** | 偏好、决策、操作配置 | `memory_search` |
| **会话上下文** | 当前对话 | (自动) |

### 搜索机制

- **关键词搜索**：精确短语匹配
- **向量搜索**：语义概念匹配
- **RRF 融合**：结合两者优势
- **多查询扩展**：捕捉未想到的表述

### 依赖

| 依赖 | 用途 | 成本 |
|---|---|---|
| Supabase (Postgres + pgvector) | 数据库 | $25/月 |
| OpenAI API | 嵌入 (text-embedding-3-large) | 按量 |
| Anthropic API | 多查询扩展 + LLM 分块 (Haiku) | 按量 |

## 部署指南

### 快速开始

```bash
# 安装
curl -fsSL https://bun.sh/install | bash
bun add github:garrytan/gbrain

# 初始化
gbrain init --supabase

# 导入
gbrain import ~/git/brain/ --no-embed

# 查询
gbrain query "我们对竞争动态了解多少？"
```

### 核心命令

```bash
gbrain stats          # 查看统计
gbrain search         # 关键词搜索
gbrain query          # 语义查询
gbrain get            # 获取页面
gbrain sync           # 同步仓库
gbrain embed          # 生成嵌入
gbrain check-update   # 检查更新
```
