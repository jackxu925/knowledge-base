### Anthropic Engineering: Scaling Managed Agents — Decoupling the Brain from the Hands

Anthropic 工程博客发布了一篇重磅文章，详细介绍了 **Managed Agents** 的架构设计理念。核心思想是将 Agent 的组件解耦：

**关键架构决策：**
- 将"大脑"（Claude + harness）从"双手"（sandbox 和执行工具）中分离出来
- Session（事件日志）、Harness（循环调用 Claude）、Sandbox（执行环境）各自成为独立接口
- 这种解耦使得 p50 首次响应延迟降低约 60%，p95 降低超过 90%

**可扩展性：**
- "多大脑"：可以启动多个无状态 harness
- "多双手"：每个大脑可以连接多个执行环境
- 大脑之间还可以传递执行环境

### No Priors — SAP: Bringing the 'Operating System' of a Company into the AI Era with CTO Philipp Herzig

**The Takeaway:** SAP 的 AI 战略不仅仅是技术转型，更是商业模式转型——从按座位许可转向消费模式，最终可能走向结果导向定价。真正的挑战不在于 AI 技术本身，而在于如何在大规模企业环境中可靠地交付业务成果。

**关键洞察：**

1. **三层变革：** SAP CTO Philipp Herzig 认为 AI 正在三个层面重塑企业软件：
   - **UI 层：** 从固定界面转向生成式 UI（Generative UI），系统变得多模态、主动化——早上醒来就告诉你供应链出了什么问题
   - **业务流程层：** 从 rigid SOP 到 Agent 驱动的灵活流程，融合结构化和非结构化数据
   - **数据层：** 构建统一的语义化数据模型，因为"AI 只和数据一样强大"

2. **规模是最大挑战：** "你可以轻松做一个 10 文档的 chatbot POC 打动 CEO，但在 SAP 我们有 20,000 个 API。当你要服务全球 40 万家企业客户时，每个问题的答案都因国家、薪资体系、税法而异——这才是真正的工程难题。"

3. **LLM 不够用于预测分析：** SAP 投入两年研发发布了 RPT-1（Relational Pretrained Transformers），专门针对表格数据的预测任务（分类、回归、时间序列）。传统 ML 方案（XGBoost、AutoML）需要大量数据科学家，而 RPT-1 旨在用少量上下文实现高精度预测。

4. **Agent Mining 取代 Process Mining：** 通过记录 Agent 的所有决策轨迹和用户输入，捕获原本存在于人们头脑中的"部落知识"，用来发现异常或优化标准操作流程——形成数据飞轮，不断产生新的 evals 来优化系统。

5. **Eval 是最重要的开发实践：** "Agentic coding 之所以有效，是因为你能验证结果——编译通过、测试通过。但在财务等领域构建可靠的 Agent，你需要定义正确的边界条件，编写 evals 来验证 Agent 是否在做正确的事。这就像 TDD 回来了，但这次是真的有必要这么做。"

6. **Jevons Paradox 在 SAP 的体现：** AI 不会减少工作岗位，而是把每个人提升一个层级——就像 junior 开发者有了 Claude Code 后变成代码审查者和架构思考者。财务共享服务中心的员工将从数据收集转向战略分析。

7. **商业模式转变：** SAP 正从 seat-based 许可转向 hybrid consumptive 模式，最终目标是 outcome-based 定价。但这需要与客户共同推进，因为企业仍需要成本可预测性。

1. **三层变革：** SAP CTO Philipp Herzig 认为 AI 正在三个维度重塑企业软件：
   - **UI 层：** 固定界面 → 生成式 UI，系统变得多模态且主动化——早上一醒来就告诉你供应链哪里有问题
   - **业务流程层：** 僵化的标准作业流程 → Agent 驱动的灵活流程，融合结构化和非结构化数据
   - **数据层：** 构建全局统一的语义数据模型——"AI 的强大程度取决于数据"

2. **规模才是真难题：** "10 个文档的 chatbot POC 就能让 CEO 眼前一亮，但 SAP 有 20,000 个 API。服务全球 40 万客户时，每个答案因国家、薪资体系和税法而不同——这才是真正的工程挑战。"

3. **LLM 不适用于预测分析：** SAP 投入两年研发发布了 RPT-1（Relational Pretrained Transformers），专为表格数据预测（分类、回归、时间序列）。传统 ML 方案需要大量数据科学家，RPT-1 旨在用少量上下文即实现高精度预测。

4. **Agent Mining 替代 Process Mining：** 记录 Agent 所有决策轨迹和用户输入，捕获存在于人脑中的"部落知识"，发现异常或优化标准操作流程——形成数据飞轮，不断产出新的 evals 优化系统。

5. **Eval 是最重要的开发实践：** "Agentic coding 有效是因为你能验证结果。但在财务等领域构建可靠 Agent，你需要定义正确的边界条件、编写 evals。TDD 这次真的回来了。"

6. **AI 提升所有人一个层级：** AI 不会削减岗位，而是将每个人提升一级——如同 junior 开发者有了 Claude Code 后转做代码审查和架构思考。财务人员将从数据收集中解放出来转向战略性分析。

7. **商业模式转向：** SAP 正从 seat-based 许可转向混合消费模式，最终目标是 outcome-based 定价。但这是与客户共同的旅程，因为企业仍需要成本可控性。
