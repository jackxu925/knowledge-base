## Podcasts

**No Priors** — "Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan"
https://www.youtube.com/watch?v=QDsbFLEt9ro

**The Takeaway**: 随着 AI agents 变得越来越自主和强大，企业面临的安全风险呈指数级增长。Onyx Security 作为"AI 安全的守卫者"，通过监控 AI agents 的行为来检测异常和潜在威胁。

**Key Insights**:

1. **从 DLP 到 Agent Security** — 两年前，AI 安全的故事是"什么是员工放进 ChatGPT 的内容？"（DLP 数据防泄漏）。现在市场普遍恐慌的是 agents 意外执行错误操作（如发布不该发布的代码和 tokens）。企业意识到风险已呈指数级增长，但苦于没有办法阻止 agents 的采用。

2. **AutoGPT 的启示** — Maxim 在 2022 年看到 AutoGPT（第一个真正自主运行在 LLM 上的 agent）后意识到：当模型变得比我们更聪明时，如何监督这些 agents？当时企业还没开始使用 agents，风投都说他们"太早了"。

3. **Reasoning Models 改变游戏规则** — 随着 Reasoning Models 能够执行长周期任务，Cloud Code 成为第一个广泛使用的自主 agent，Anthropic 的收入也来自企业使用 Claude Code 完成开发者过去做的工作。Agents 终于在"太晚"之前到来了。

4. **企业面临的数据隐私困境** — 企业愿意让 Onyx 这样的第三方查看 agents 的历史行为数据，因为知道 Anthropic 和 OpenAI 这样的公司会想用这些数据来训练模型。这是大型 AI 公司做不了但 Onyx 可以做的事情。

5. **多vendor世界的安全挑战** — 未来世界会有多种不同 vendor 的 AI models（因为成本原因使用开源模型，因为特定任务效果更好使用不同模型等等）。期望所有 vendors 提供同等水平的安全是不现实的。

6. **以色列安全产品哲学** — 以色列的安全产品之所以强，是因为深刻理解安全团队如何工作。产品不仅要解决技术问题，还要被安全团队真正喜爱。需要了解他们早上上班做什么、打开什么系统、老板要什么、同事要什么。

7. **Human 到 Agent 的过渡** — 现在卖产品给"人类+少数 agents"的受众，但这个受众群体正在快速转向纯 agents。需要让系统对 agents 同样友好——比如不在对话中浪费过多 tokens。
