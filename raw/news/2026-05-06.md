## 1. Claude Code 源码泄露：AI Agent 安全危机升级

**事件概述**
- 512K行 Claude Code 源码泄露，泄露后数天内即发现多个关键漏洞
- 主要漏洞类型：
  - shell命令拒绝规则在50个子命令后静默失效
  - MemoryTrap漏洞允许恶意内存跨会话和用户传播
  - 通过compilation实现上下文投毒
  - shell解析器差异导致沙箱绕过

**值得关注的原因**
- AI Agent 安全从理论威胁转变为现实风险
- Anthropic Mythos 已展示32步自主网络攻击能力
- 企业需立即从模型级安全转向基础设施级安全控制
