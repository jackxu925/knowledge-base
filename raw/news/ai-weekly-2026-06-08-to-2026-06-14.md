# AI 周报 2026-06-08 至 2026-06-14

> 关注过去一周 AI 领域的重要动态，侧重 AI coding 与具身智能方向

## AI Coding 工具

### 1. 小米发布开源终端AI编程助手 MiMo Code

**值得关注的原因：**
- 首个基于国产全功能 GPU 全栈训练的代码大模型，含 9B 和 27B 两个参数规模
- 后训练流程在基于 MTT S5000 的夸娥智算集群上完成
- 支持从 PyTorch 标准算子自动生成高性能 CUDA/MUSA 原生 Kernel 代码
- 在 KernelBench 评测中，MusaCoder-27B-RL 以 Overall Pass@8 93.2%、Avg.@8 88.60% 超越 Claude Opus、DeepSeek-V4 Pro、GLM-5.1、Kimi K2.6 等主流 SOTA 代码模型
- 核心能力包括持久记忆系统和无限上下文，通过独立 subagent 自动保存状态解决长会话遗忘
- 独创 Compose 模式实现模型与 Agent 协同优化

**来源：** IT之家

---

### 2. Cursor Bugbot 重大更新

**值得关注的原因：**
- 运行速度提升超 3 倍，成本降低 22%
- 每轮审查多发现 10% 的 bug，90% 的运行在三分钟内完成
- 新增 `/review` 命令，可在推送代码前运行 Bugbot 和安全审查
- 与 GitHub/GitLab 同步，若已通过 `/review` 审查过同一 diff，打开 PR 时 Bugbot 会自动跳过并备注
- 支持配置仅审查 PR 中新增内容

**来源：** Cursor Blog

---

### 3. DiffusionGemma：文本生成速度提升 4 倍

**值得关注的原因：**
- Google DeepMind 发布开源实验模型，采用文本扩散技术
- 突破自回归逐 token 生成方式，每次前向并行生成 256 个 token
- 26B MoE 模型推理时仅激活 3.8B 参数，量化后适配 18GB 显存消费级 GPU
- 在 H100 上达 1000+ tokens/s，RTX 5090 上 700+ tokens/s
- 具备双向注意力和自我修正能力，面向内联编辑、代码填充等本地交互工作流
- 以 Apache 2.0 许可证开放

**来源：** Google DeepMind Blog

**值得关注的原因：**

- 含 9B 和 27B 两个参数规模，在 KernelBench 评测中超越 Claude Opus、DeepSeek-V4 Pro
- 支持从 PyTorch 标准算子自动生成高性能 CUDA/MUSA 原生 Kernel 代码
- 标志着国产 AI 芯片在代码生成领域的重要突破

**来源：** IT之家

## 具身智能

### 9. 华为云发布全球首个端到端具身 AI 平台 CloudRobo

**值得关注的原因：**
- 覆盖从数据、模型到部署、集成的全生命周期
- 基于 PB 级可信数据底座
- 在 INSPIRE2026 上展示了核心能力：数据与模型双评估系统、主动力控模型快速组装、机器人小时级上云、模型分钟级部署
- 标志着中国在具身智能领域的重要进展

**来源：** 华为云

### 10. WEAVER：更优、更快、更长的机器人操作世界模型

**值得关注的原因：**
- 一种多视图世界模型架构，通过流匹配损失训练预测未来潜变量和奖励值
- 在机器人操作任务上，WEAVER 在政策评估中与真实成功率的相关系数 ρ=0.870
- 在 π0.5 基础模型基础上实现政策改进成功率提升 38%，测试时规划成功率提升 14%
- 速度比先前世界模型快 5-10 倍
- 在分布外场景下表现也优于先前世界模型
- 代码、模型和视频已开源

**来源：** HuggingFace Daily Papers

## 总结

过去一周的 AI 动态显示：

1. **AI Coding 领域持续创新**：小米和摩尔线程等国内厂商推出开源代码模型，标志着国产化替代的重要进展；Cursor 等工具持续优化提升开发者体验；DiffusionGemma 等新技术突破带来性能提升

2. **具身智能平台化**：华为云发布首个端到端具身 AI 平台 CloudRobo，WEAVER 等世界模型持续进步

3. **成本优化成为焦点**：从 Fusion API 到 /architect 项目，各方在探索如何降低 AI 使用成本
