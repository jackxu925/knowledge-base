# 安欣餐厅点菜系统

## 概述

为安欣餐厅打造一个点菜系统（App / 小程序 / Web）。

## 状态

- [ ] 待细化：明确平台形式（微信小程序？Web？收银端？）
- [ ] 待细化：明确核心功能需求
- [ ] 待细化：了解现有技术条件和部署环境

## 初步想法

- 需求来源：徐衡
- 目标用户：安欣餐厅的顾客（扫码点菜）或服务员（手持终端）
- 核心场景：顾客入座 → 扫码 → 浏览菜单 → 选菜下单 → 后厨接单 → 上菜

## 待确认问题

1. 平台选择：微信小程序（顾客端） + 管理后台（Web）？还是其他组合？
2. 菜单管理：菜品是否需要分类、图片、规格（大/中/小份）、口味备注？
3. 支付方式：微信支付？还是只下单、前台统一结账？
4. 是否需要：排队叫号、会员系统、优惠券、历史订单？
5. 后厨是否有打印机/接单屏？需要对接什么硬件？
6. 现有系统：是否已有收银系统或 ERP 需要对接？
